## Limites desta revisão

- A ausência de COEP é um alerta **Low** do ZAP. Os MFEs são carregados por origem cruzada via Module Federation; COEP não foi habilitado sem uma validação específica de compatibilidade com esses remotes.
- O `style-src-attr 'unsafe-inline'` permanece para os atributos `style` emitidos por componentes. `script-src` continua protegido por nonce; o ZAP final classifica o aviso de CSP como **Low**.
- Os controles de logs/alertas de S4-01, supply chain de S3-09 e publicação/headers da plataforma não foram alterados nesta task.
